# SIMA Edge 故障教训：哪些边界要在 OneX 重写时固定

下列是不同故障，不是同一条“网络不稳定”的因果链。文件引用为 SIMA 仓库路径，日期由文件名给出；OneX 建议不是 SIMA 已验证的实现。

## 登录：不要混淆租户名称、签名身份和本次访问入口

SIMA 先把显示名存成租户 ID，改正后仍失败：旧安装以签名配置的内网 canonical 地址构造会话，服务端却返回用户选中的公网 origin。同一用户具备资格也无法通过工作域比较；双入口测试复现。修复保留签名校验，但用明确选中的入口绑定租户会话，绝不为解决登录去放宽成员资格或混合历史。依据：`docs/reports/desktop-oc-login-20261115.md:10-25`。

**OneX：** 登录选择器按目录返回的稳定 ID 提交；把发行签名身份、连接入口、租户/工作域分别建模。验收用两个合法入口和相同显示名的不同租户，断言请求只投递到确认的入口，失败不清空原工作区。

## 配置同步：账户真的变了，还是本次登录失效了？

0.3.18 能复现登录后的同步鉴权错误被 `DESKTOP_ACCOUNT_CHANGED` 覆盖。0.3.19 的判据是同一后台、账户代次、登录序号，且仅有效位变化时保留原拒绝；迟到的旧账户结果仍不得写回。独立测试通过，受影响机器并未由该报告代签。依据：`docs/reports/desktop-login-error-20261118.md:3-12`（修复提交 `ef7e81d7`）。

**OneX：** 同步结果携带账户代次和配置修订号，区分暂不可达、鉴权拒绝、旧响应被丢弃。原错误仅作脱敏分类，不让通用“离线”提示吞掉它。测试按顺序注入同步中登出、换号、后台替换以及同一登录被拒四种结果。

## 对话中断：前台失联不等于 daemon 死亡

Windows Kimi 前台报 daemon 丢失，但后台记录的是 `cli_disconnected`、回收已确认，随后设备仍有心跳。已证实的候选机制包括：管道超时后忽略实际完成结果、前台输出阻塞拖延心跳。现场缺具体 RPC 阶段和 OS 错误，不能把任何一个机制定为唯一首因。依据：`docs/reports/c-si-bus-poc-20261025/windows-kimi-daemon-lost-20261027.md:5-27`。

**OneX：** 将 UI、受管进程和后台控制连接分别观测；心跳不依赖终端渲染。记录 launch、阶段、耗时、退出码与回收状态。只在确定未发送请求时有界重连；已经可能被执行的工具输入或模型请求不能自动重放。

## 续约：剩余时间和授权对象都要比较正确

- **调度错误可复现。** 短授权下连续两次 503，旧退避能睡过截止时间。按剩余寿命限制等待可在原期限前续成；不应据此放行已过期请求。另一次现场 `UPSTREAM_STREAM_INCOMPLETE` 发生时授权仍有效，缺对应模型观测，不属于已证实的续约故障。`docs/reports/deepseek-grant-refresh-deadline-20261116.md:5-9,23-26`。
- **比较对象错误可复现。** 把重写后的 relay URL 当授权对象，切换已验证的 LAN/公网入口会误拒续约；反过来，同一 relay URL 又会掩盖真正的上游变化。修复比较重写前的绑定与别名集合。现场只有 `BINDING_CHANGED`，没有具体字段，不能认定唯一根因。`docs/reports/deepseek-renewal-binding-20261116.md:5-16,20-24`。

**OneX：** 以单调时钟估算剩余租期，给网络超时和重试预留预算；允许轮换令牌，不允许悄悄换租户、模型、上游或提高额度。分别测试入口切换应续、授权对象变化应拒、服务恢复太迟必须停。将拒绝、过期、网络暂不可达、上游流中断分开记录。

## 中继：不要让控制面的波动进入每一片模型输出

SIMA 的路由重写让传输入口变化参与了模型绑定比较（见上一节），是增加一跳造成耦合的具体证据。OneX 立项访谈也把 Server 中继列为链路过长的问题，决定由 Edge 就地转发（`docs/kickoff/goal-interview-20261119.md:24-30,55-59,79-85`，此路径在 OneX）。这不是所有断流都由中继造成的证明。

**OneX：** 数据路径固定为 Agent → 本机 router → 获准上游；Server 下发配置与租约，另收 transcript 和用量。控制连接短断不拆仍有有效授权的本机对话；到期不放行，已发请求不重放。用同一 launch 关联租期、最后一次续约、上游首片/终态、transcript 游标和 ACK；对照注入“仅控制连接断”和“仅流式上游断”，诊断 API 必须能分辨，且不展示凭据或正文。
