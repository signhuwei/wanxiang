**集成签收条件：**

1. 在原生→WebView 边界为全部阶段和错误返回建立明确的字段白名单，而不是把 daemon 状态或原始异常直接序列化。用合成标记覆盖登录成功/失败、启动失败、断线、注销，检查完整 IPC 回包、UI 提示和日志中均无标记；核实服务地址只返回规范化 origin，不携带用户信息、路径、查询或片段。
2. 生产包只从本地加载该窗口；核对最终 WebView 的命令能力、导航策略与有效 CSP。`index.html:2` 的 `connect-src 'self' ipc: http://ipc.localhost` 允许同源连接及 IPC；这是允许项，不是已发生的直连。分别观察窗口和原生进程：登录/选租户/启动时 WebView 只有本地资源与 IPC，Server/上游通信不得来自 WebView。测试工具不随包交付。
3. 推荐 UI 对未分类的桥异常统一给出安全提示，不直接展示异常 `.message`；桥仍须负责源头裁剪快照和错误，UI 掩码不能撤销已经跨过边界的数据。
